# 2026-08-13 작업 정리

기준 브랜치: `boguk3`

## 영업 시퀀스

- 영업을 손님 수 제한 방식에서 기본 180초의 시간 제한 방식으로 변경했다.
- 손님 풀에서 가중치와 기본 100초 쿨다운을 적용해 손님을 계속 선택하도록 구성했다.
- 모든 손님이 쿨다운 중이면 쿨다운을 무시하고 한 명을 선택하는 폴백을 추가했다.
- 필수 손님과 필수 인카운터를 우선순위 큐로 처리하며, 제한시간이 끝나도 필수 큐와 진행 중인 주문/인카운터는 끝까지 완료한 뒤 정산하도록 했다.
- 인카운터 중에도 영업 타이머가 계속 흐르며, 종료 후 남아 있는 영업 상태로 복귀하도록 했다.
- `EpisodeType.Encounter`와 영업-에피소드 연결을 추가하고 `EpisodeManager`/`EpisodeRunner`는 합의한 범위에서 최소 수정했다.
- 판매 금액은 `RecordDrinkSale()`로 기록하고 정산 시 지급하도록 했으며, 즉시 지급 정책을 확장할 수 있게 분리했다.

## 바텐딩 및 얼음

- 영업 씬과 개발용 샌드박스가 같은 세션 생성 로직과 설정 데이터를 사용하도록 정리했다.
- 얼음통, 얼음 큐브, 얼음 프리팹과 배치 설정을 추가했다.
- 얼음과 액체가 잔/비커/셰이커 이동 시 같은 운반 규칙을 따르도록 했다.
- 셰이커 이동 및 스트레이너 사용 시 얼음 보존/배출 규칙을 연결했다.
- 술장 재료 클릭 시 하단 슬롯에 병이 생성되고, 중복 생성은 거부되도록 복구했다.
- 병·잔·비커·셰이커의 우클릭 회전 중/복귀 중에도 마우스 좌우 이동을 따라가며, 복귀 순간 커서로 튀는 현상을 방지했다.
- 병/잔 형상과 얼음 배치를 시각적으로 확인할 수 있는 샌드박스 및 레이아웃 미리보기 도구를 추가했다.

## 서빙 및 정보 표시

- 잔을 들면 현재 주문 손님 위에 반투명 서빙 영역을 표시한다.
- 여러 캐릭터 뷰가 있어도 내부적으로 하나의 손님 영역으로 합쳐 처리한다.
- 잔을 든 채 영역 중심을 클릭하면 한 번만 서빙되도록 했다.
- 슬롯 위 잔·비커·셰이커 옆에 전체 용량과 액체별 용량을 표시한다.

## 플레이테스트 도구

- 대량 손님 풀, 쿨다운 폴백, 가중치 선택을 검증하는 스트레스 테스트를 추가했다.
- 영업 타이머/인카운터/정산 연결 검증기를 추가했다.
- 얼음 배치·이동·스트레이너와 술장 병 생성 검증기를 추가했다.
- 서빙 영역, 용량 표시, 회전 이동, 액체/얼음 운반을 한 번에 검증하는 `BartendingInteractionValidator`를 추가했다.
