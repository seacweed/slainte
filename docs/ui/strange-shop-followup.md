# 이상한 상점 추후 구현 메모

작성일: 2026-08-19
상태: 이상한 상점 전환만 보류 — 일반 상점 이미지는 현재 휴식 배경/TV 작업에 포함

## 목적

휴식 화면의 기존 일반 상점에는 이번 작업에서 제공된 OFF 이미지 세트를 적용한다. 에피소드 조건에 따라 이상한 상점으로 전환되는 기능과 ON 이미지 세트 적용만 추후 별도 작업으로 남긴다.

## 현재 상태

- `RestScene`에는 `ShopButton`과 `ShopWindow`가 있으며, 클릭하면 기존 상점 UI가 열린다.
- `ShopUIManager`에는 재료 카테고리, 상품 구매, 업그레이드, 보유 금액 표시가 구현돼 있다.
- 위 기능은 일반 상점 기능이며, 이상한 상점 전용 활성 조건과 연결돼 있지 않다.
- 이상한 상점 ON/OFF 이미지 교체와 에피소드 조건 연결은 아직 없다.
- TV 방송의 `DisableRestShop` 효과 데이터와 런타임 판정은 현재 일반 `ShopButton`에 연결돼 있다.

## 현재 이미지 작업에 포함하는 일반 상점 범위

- 기본 상태: `휴식 배경_(이상한동전off).png`
- 강조 상태: `휴식 배경_(이상한동전off_테두리) - 복사본.png`
- 회색 상태: `휴식 배경_(이상한동전off_회색).png`
- 새 일반 상점 이미지 위치에 맞춘 `ShopButton` 콜라이더 교체
- 기존 클릭 동작과 `ShopUIManager` 재사용
- TV의 `DisableRestShop` 방송 효과를 기존 일반 상점에 연결

파일명의 `이상한동전off`는 이상한 상점 전환 전 상태를 뜻한다. 현재 작업에서는 이 세트를 일반 상점의 고정 외형으로 사용한다.

## 현재 작업에서 제외하는 항목

- `이상한동전on` 이미지 세트 적용
- 에피소드 조건에 따른 OFF/ON 이미지 세트 자동 전환
- 이상한 상점과 `EpisodeData` 활성 조건 연결
- 이상한 상점 전환 전후의 클릭 정책 변경

기존 `ShopWindow`, `ShopUIManager`의 기능은 유지하고, `ShopButton`은 새 이미지에 맞춰 위치와 콜라이더 및 TV 이용 제한 연결만 갱신한다.

## 추후 구현 방향

1. 이상한 상점에 연결할 `EpisodeData`를 Inspector 참조로 받는다. 에피소드 ID나 플래그 이름을 코드에 하드코딩하지 않는다.
2. 해당 에피소드 에셋의 기존 활성 조건(`triggerCondition`)을 `EpisodeManager.IsUnlocked()`로 평가한다. `requiredFlags`, `blockedFlags`, 선행 에피소드, 변수 조건 등 기존 조건 체계를 그대로 사용한다.
3. 조건 미충족 시 현재 작업에서 적용한 OFF 이미지 세트를 유지하고, 조건 충족 시 ON 이미지 세트로 전환한다.
4. 휴식 화면의 공통 시각 상태 규칙에 맞춰 일반/노란 테두리/회색 이미지를 전환한다.
5. 조건 미충족 상태에서도 클릭 가능한지, 또는 콜라이더를 비활성화할지는 기획 확인 후 결정한다. 클릭을 막는다면 잠금 사유를 표시할지도 함께 정한다.
6. 조건 충족 상태의 클릭은 기존 `ShopUIManager`를 열도록 연결하여 현재 구매·업그레이드 기능을 재사용한다.
7. TV의 `DisableRestShop` 방송에 따른 일반 상점 이용 제한은 현재 TV 작업에서 구현한다. 추후 이상한 상점 전환 후에도 같은 제한 규칙을 그대로 적용할지 확인한다.
8. OFF/ON 이미지가 동일한 오브젝트 영역을 사용하지 않는 경우에만 이상한 상점 전환 시 콜라이더를 추가 조정한다.

## 이미지 적용 주의사항

- 제공된 이상한 상점 원본은 1440×1440 캔버스이며 QHD 화면의 왼쪽 1440px 영역에 정렬한다.
- 일부 상점 이미지에는 본체에서 멀리 떨어진 불필요한 불투명 픽셀이 있다. 원본을 수정하지 않는다면 실제 오브젝트 영역만 포함하도록 Sprite Rect를 지정한다.
- ON/OFF, 테두리, 회색 이미지들은 같은 기준점과 크기를 사용해 상태 전환 시 흔들리지 않게 한다.

## 완료 조건

- 에피소드 에셋의 활성 조건 변경이 코드 수정 없이 이상한 상점 상태에 반영된다.
- ON/OFF 및 상호작용 상태가 저장 데이터를 불러온 직후에도 정확하다.
- 상태 전환 시 이미지 위치가 움직이거나 겹치지 않는다.
- 비활성 상태와 TV 방송 제한 상태에서 정해진 클릭 정책이 일관되게 적용된다.
- 기존 상점의 구매, 업그레이드, 금액 갱신 기능에 회귀가 없다.
