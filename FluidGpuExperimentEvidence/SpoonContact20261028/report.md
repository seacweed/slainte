# 스푼 우클릭 충돌

사용자의 정정에 따라 **스푼은 잡고 있을 때 통과하고, 우클릭을 누르는 동안만 다른 고체와 충돌**하도록 변경했다. 우클릭은 스푼을 회전시키거나 커서를 잠그지 않으며 마우스 이동은 계속 따른다. 버튼 해제·Esc·포커스 이탈·입력 장치 교체·놓기·Reset·비활성화 때 충돌 모드를 해제한다. 내려놓은 스푼은 원래 고체 충돌 설정으로 복원한다.

`FluidExperimentBody.SpoonContacts.cs`에서 일시적인 상태와 원래 콜라이더 trigger/full-kinematic 설정을 보관한다. 잡은 스푼의 기본 통과는 trigger로 처리하고, 우클릭 중에는 원래 고체 플래그와 full-kinematic 접촉을 사용한다. 충돌 중에는 기존 완료된 물리 이동 경로로 위치를 갱신한다. World의 잡힌 개체 충돌 무시 정책에서 이 상태만 예외로 처리하며, 분리한 셰이커 부품과 유리 파편의 접촉 정책에도 연결했다. 일반 병·잔·셰이커의 회전과 잡기 정책은 유지한다.

액체 GPU 경계·혼합·Stir 시간/균일도 조건은 수정하지 않았다. 실제 Stir 테스트를 충돌이 켜진 스푼으로 실행했다. 이전 상하 반전 프리팹과 그림/프로파일/씬/설정/레시피도 동일하게 유지했다.

## 검증 결과

Unity 6000.3.5f2 / D3D11 / RTX 3070, 원본 프로젝트를 저장하지 않는 격리 프로젝트에서 실행했다.

| 실행 | 내용 | PASS |
|---|---|---:|
| 02-input-native-final | 실제 가상 마우스 입력 → Interactor.Update, 통과/충돌 전환·회전 차단·마우스 이동·네이티브 접촉·부품·취소/복원 | 47 |
| 03-stir-cocktails | 충돌을 켠 스푼의 Stir와 기존 실제 레시피·평가·제조법 | 61 |
| 04-input-regression | 기존 병 회전·입력 연속성·셰이커 조작 | 1,925 |
| 05-shards | 기존 파편 운동·접촉·액체 보존 | 76 |
| 06-runtime | 독립 Runtime·디스펜서·Reset | 29 |
| 07-garnish | 기존 가니시 물리·소유권·모드 전환 | 170 |
| 합계 | | **2,308** |

전 실행 exit 0, timeout false다. native 테스트는 고의로 병과 스푼을 겹친 동일 배치에서 기본 통과 때 충돌 콜백/병 이동이 없고, 우클릭 후 충돌 콜백 5회와 병 이동이 생기는 것을 확인했다. 이는 접촉 활성화 확인용 배치이며 힘의 자연스러움을 평가한 측정은 아니다. 분리한 스트레이너의 충돌 무시도 버튼 상태에 따라 즉시 바뀐다. OS 커서 잠금/표시는 건드리지 않았다. 직접 사람의 마우스 조작 감각은 별도다.

최초 01-input-native의 성공 기록도 보관했다. 위 합계에는 부품 즉시 갱신을 추가한 최종 02 실행만 포함했다. 기존 가니시 검증은 이전 표시 순서 수정 때 보관한 현재 정책의 검증 사본을 사용했다.

변경 전 1,335개 파일 중 1,328개 동일, 허용한 기존 코드·설명 7개만 수정했다. 새 런타임 partial 소스 1개와 meta를 추가했다. 원본/검증 프로젝트의 최종 소스 497개가 일치하고 GUID 오류·예상 밖 변경이 없다. PhysicsLab과 기존 게임 Runtime도 보존했다. 각 실행 폴더에 명령, 소스와 harness 해시, 로그, 결과, 종료 코드를 보관했다.
