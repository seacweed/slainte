# 호스·디스펜서 복귀 및 파편 방향 수정 — 2026-10-21

**수정 및 검증 완료: 8개 실행 정상 종료, PASS 4,705개, FAIL 0개.** 이번 변경은 기존 얼음·가니쉬 및 액체 수정 위에서 이어서 수행했다. 사운드 작업자의 검토를 위해 AudioPlanning, 기존 오디오 코드, 음원, Packages/Wwise는 수정하지 않는다. 향후 Wwise와 충돌 강도별 사운드를 사용한다는 사용자 지침은 별도 사운드 구현 단계에 적용한다.

## 변경

- 호스 기본 폭 0.065→0.115u. 끝을 고정한 120Hz 내부 적분, 시간에 따른 감쇠, 중력과 곡선 복원력을 사용한다. 물리 노드 사이를 Catmull–Rom으로 세분화하고 끝을 둥글게 그린다. 호스에 고체 충돌은 추가하지 않는다.
- 디스펜서의 복귀 전 구간을 kinematic/trigger로 유지하고 GPU 충돌·표면 가림에서도 제외한다. 장애물 우회/중간 충돌 복원은 제거했다. 수납 뒤에는 이동 방향과 거리에 따른 작은 회전 반동이 감쇠하며, 재고와 배출은 정지 상태를 유지한다.
- 디스펜서는 잡는 입력 프레임에 수직이 되고 회전 흔들림을 취소한다. 실제 잡은 로컬 지점이 커서 아래에 남도록 잡기 오프셋을 다시 계산한다. 일반 잔 회전 경로는 디스펜서에 적용하지 않는다.
- 파편 초기 운동은 충돌 후의 `GetPointVelocity` 대신 충돌 직전 선속도·각속도와 실제 법선 충격 벡터 및 접촉점 토크를 조합한다. 더 강한 실제 충격의 추가 퍼짐은 면적 가중 중심을 기준으로 분리한다. 충돌 전 표본이 없는 제어 파손은 이미 반영된 충격을 또 더하지 않는다.
- Natural/Explosive 스타일과 기존 파손 임계값 6/4는 유지한다. 파편 운동만 바꾸며, 잔에 들어 있던 액체·얼음·가니쉬에 잔 속도나 추가 충격을 다시 주지 않는다.

## 검증 경계

실제 Unity 6000.3.5f2/D3D11 GPU와 Physics2D를 독립 사본에서 실행한다. 수동 틱과 실제 자동 업데이트를 구분한다. 원본 프로젝트를 Unity로 열거나 저장하지 않으며 Computer Use를 사용하지 않는다.

초기 `v1` 실행은 두 항목에서 실패했다. 호스의 중력 전용 형태가 프레임률에 따라 다른 정지 곡선으로 남아 곡선 복원력을 추가했다. 파편 강도 비교는 파손 임계값을 뒤늦게 넘은 접촉을 비교해 첫 충돌 이후 운동이 섞였으므로, 강도 비교 전용 fixture만 첫 native 접촉에서 깨지도록 분리했다. 실제 플레이 기본값 6/4의 낙하/벽/채워진 잔 검사는 별도로 유지한다. 실패 기록은 삭제하지 않는다.

[최종 감사 JSON](audit.json)에 실제 종료 코드·시간 초과·Unity 오류·실행 소스 해시·이번 작업의 변경 범위를 기록했다. 자동 물리/오프스크린 그림 확인은 직접 플레이 체감이나 최종 음향 검증을 대신하지 않는다.

- 호스 폭 **0.115u**, 두 끝의 실제 연결점 일치. 30/60/120Hz 호출 스케줄에서 좌표가 유한하고 심한 국소 늘어남이 없었다. 30Hz와 120Hz의 마지막 정지 곡선 최대 차이는 **0.00002543u**였다. 이는 호스 업데이트 스케줄 비교이며 게임 전체가 120fps로 실행됐다는 의미는 아니다.
- 수동 틱에서 수납 후 각도는 **+9.436° / -4.341°**로 양쪽으로 움직였고, 마지막 5–6초 구간의 절대 각도는 **0.019° 이하**였다. F/G 실제 자동 FixedUpdate에서도 같은 방향 반전과 감쇠를 확인했으며 마지막 관찰 구간은 **0.042° 이하**였다.
- 흔들리는 디스펜서를 실제 Pick하면 그 입력 프레임에 0°가 되고 잡은 로컬 지점이 커서 아래에 남았다. 일반 물체용 회전 API와 가상 입력의 RMB 배출은 디스펜서를 회전시키지 않았다.
- 초기 겹침·바닥/벽 밖·복귀 경로 장애물을 통과했다. 복귀의 모든 관찰 틱에서 native trigger를 유지했고 GPU 경계와 표면 가림에서도 제외됐다. 동적 장애물을 밀지 않았고, 복귀 완료 뒤 기존 수납 충돌 정책을 복원했다.
- 첫 native 접촉을 비교하는 방향 fixture에서 오른쪽으로 들어오는 속도 9의 타격은 파편 평균 x 속도 **+4.607**, 반대 방향은 **-4.606**이었다. 같은 방향 속도 15에서는 **+7.678**이었다. 이 강도 비교는 앞서 설명한 낮은 fixture 임계값으로 첫 접촉을 분리한 결과다. 실제 게임의 6/4 임계값 검사는 기존 자연 낙하·벽 충돌·40ml/얼음/가니쉬를 포함한 낙하 검사로 별도 통과했다.
- 충격 전달 비율을 0으로 둔 native 비교에서 충돌 직전 선속도 **(0, 2)**와 회전 **80°/s**가 각각 유지됐다. 기존 솔버 뒤 속도를 읽는 구현이었다면 놓치는 조건이다. Natural/Explosive의 기존 제어 파손 상속·그림·파편 수·바닥 정착·액체/내용물 보존 회귀도 통과했다.
- 실제 자동 업데이트 F/G에서 배출·반환·회전 감쇠를 확인했고, 재사용 런타임의 독립 World/명시적 카메라/환경에 맞춘 수납 위치 검사도 통과했다. 기존 입력·쉐이커, 얼음 두 모드, 가니쉬·액체 놓기 관성 검사를 함께 실행했다.
