# 스푼 우클릭 용기 상호작용

우클릭 중 외부 고체를 통과하고, 실제 용기 내부의 안전한 공간으로 들어가면 그 용기 소유 액체에만 접촉한다. 용기 벽은 스푼의 이동만 제한한다. 잔의 위치·회전·속도·질량·constraints를 고정하거나 덮어쓰지 않고, native 충돌 임펄스를 전달하지 않는다. 우클릭 회전과 커서 잠금은 없다.

이미 빈 내부 공간에 들어간 상태에서 우클릭하면 위치가 튀지 않고 활성화한다. 실제 벽에 파고든 상태면 통과 상태로 대기하고 액체에 영향을 주지 않는다. 안쪽으로 이동해 실제 콜라이더 겹침이 풀리면 활성화한다. 대기 중 버튼을 놓으면 위치 보정 없이 해제한다. 정상 진입 후에는 잔을 밀지 않는 벽 sweep과 실제 콜라이더 여유 보정을 스푼에만 적용한다. 열린 입구로 꺼내기·우클릭 해제·Esc·포커스 이탈·장치 교체·놓기·Reset·비활성화도 검증했다.

## 검증

Unity 6000.3.5f2 / D3D11 / RTX 3070 격리 프로젝트에서 실제 입력 Update 경로와 GPU 입자를 검증했다. 4종 잔(highball, rock, martini, hurricane), 기울어진 잔, 빠른 좌우/하향 이동, 움직이고 회전하는 잔의 pose/velocity 보존, 실제 native 벽 간격, 겹친 상태 우클릭 진입을 확인했다. 벌어진 잔에 큰 가로 이동을 주면 열린 입구를 따라 스푼이 빠져나올 수 있으며, 이 경우 스푼의 모든 꼭짓점이 입구 밖인지 별도로 확인했다.

표면 접촉 반경에 둔 실제 GPU 입자는 우클릭 중 해당 잔 소유일 때만 스푼에 반응했다. 같은 위치의 자유 액체와 우클릭을 끈 경우는 반응하지 않았다. Stir는 우클릭 중 실제 소유 용기의 액체 접촉으로 제한하며 시간·균일도 임계값은 유지했다.
