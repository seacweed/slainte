# 병 프리팹 참조 정리 — 2026-11-04

`FluidGpuComparison.unity` 기준으로 병 15종과 카탈로그, 초기 배치 3개의 연결을 점검했다. 15종은 이미 서로 다른 충돌 프로필을 사용하는 개별 프리팹이며, 모두 올바르게 등록되어 있었다. 현재 개별 형상과 프리팹 경로/GUID를 유지한다.

- 기존 카탈로그 항목도 재사용 런타임 에셋 빌드 시 병 원본의 재료·표시 이름·분류로 갱신하도록 수정했다. 항목 ID를 보존하며 반복 빌드로 중복을 만들지 않는다.
- 참조 검사에 누락된 병 등록, 중복 재료 ID, 재료 ID와 파일 이름, 병 외형·선택 Trigger·고체 Collider, 유한한 충돌 형상·주입구·배출 방향, 용량·붓기 값, 씬 원본 연결 검사를 추가했다.
- 초기 병 3개의 원본과 동일한 이름 덮어쓰기를 제거했다. 배치 Transform과 동작 설정은 그대로다.
- `Validate Prefab References` 메뉴 및 `Build Reusable Runtime Assets` 메뉴의 사용법을 README에 적었다.

별도 Unity 6000.3.5f2 프로젝트에서 [참조/카탈로그 검사 20개](02-references/prefab-readiness-validation.txt) 통과, 종료 코드 0. 실험 씬과 런타임 샘플 참조, Designer 잔 ID 보존도 통과했다. 첫 실행은 검증 코드의 지역 변수 이름 중복으로 컴파일 실패했으며 이를 수정한 실행이 최종 결과다.

복원 전 기준 602개 파일 중 598개는 그대로이며, 병 프리팹 15개와 모든 메타/GUID, 물리·액체·평가 런타임 코드, ProjectSettings는 변경하지 않았다. 변경은 Editor 코드 2개, 실험 씬의 이름 덮어쓰기, README뿐이다. 직접 조작 검증은 하지 않았다. 상세 변경은 [changes.patch](changes.patch), 전체 목록은 [summary.json](summary.json)에 남겼다.
