# 액체 표현 비교 버전 — 2026-11-04

현재 적용한 버전은 수면 위쪽 윤곽의 하이라이트와 아래쪽 윤곽의 약한 음영만 추가한다. 반투명 얼음은 이미 뒤쪽 액체와 알파 합성되므로 추가 틴트는 제외했다. 얼음 프리팹의 불투명도 55%, 원래 재질과 색은 유지한다. 광학 굴절·유리 메니스커스·물리 계산 변경은 포함하지 않는다.

샌드박스 상단 `Polished look` 버튼을 켜거나 꺼서 리셋 없이 비교할 수 있다. 비교는 [기존 화면](07-surface-only/before.png), [개선 화면](07-surface-only/after.png), [좌: 기존 / 우: 개선](07-surface-only/comparison.png)에 남겼다. 실제 3종 잔과 재료, 얼음의 고정 상태를 D3D11/RTX 3070으로 렌더링했다. 표현 차이는 얇은 가장자리에 한정된다.

## 검증

별도 Unity 6000.3.5f2 프로젝트에서 [표현 검사 17개](07-surface-only/liquid-polish-validation.txt), [기존 칵테일 검사 61개](08-cocktail/cocktail-integration-validation.txt), 총 78개 통과. 두 실행 모두 종료 코드 0이며 현재 소스 479개 해시가 실행 기록과 일치한다.

표현 전후의 액체 color/coverage 텍스처, GPU 입자·성분·온도·기법 상태와 물체 pose/속도는 일치했다. 얼음 원본 재질과 불투명도를 유지했다. 화면 크기 변경과 원래 표현으로의 복귀를 확인했다. 최종 실행의 복귀 화면은 원래 화면과 픽셀 차이 0이었다. 검사 허용치는 가산 half-float 텍스처의 희소한 누적 오차를 위해 최대 2/255, 전체 픽셀의 0.01% 이내다.

렌더링·GPU·애플리케이션 오류는 없었다. 기존 compute 셰이더 경고는 남아 있다. 사람이 직접 조작하는 플레이와 동적 수면의 자연스러움, 성능은 검증하지 않았다.

## 보존과 이력

기준 1,319개 파일 중 1,313개는 그대로다. 변경은 설정 스크립트·설정 에셋·표면 표시 shader·표시 속성 연결·샌드박스 토글·README 6개다. 모든 프리팹과 GUID/meta, 물리 및 compute 코드, 기존 평가기, 기존 게임 런타임·PhysicsLab·아트·ProjectSettings는 보존했다. [changes.patch](changes.patch)에 이번 변경만 기록했다.

초기 얼음 틴트 시안은 `RejectedIceTint`에 보관하고 활성 소스에서 제거했다. 01/02 실행에서는 MaterialPropertyBlock을 MonoBehaviour 필드 초기화 시 생성한 오류를 발견했고 렌더 시 생성으로 수정했다. 03 실행은 고정 비교 fixture의 스프라이트 Transform 보간 위치가 Rigidbody와 달라 실패하여 완료 pose를 명시적으로 반영하도록 수정했다. 04 실행은 해상도 변경 후 복귀 화면 20픽셀에서 최대 2/255 차이를 보였고, 누적 텍스처의 수치 허용치를 명시해 05/06에서 검증했다. 05/06은 추가 틴트가 포함된 과거 시안이며 최종 상태 근거는 07/08이다.
