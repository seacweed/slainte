호스의 줄 형태 수정 및 재현 검사 — 2026-10-22

호스가 관처럼 모양을 유지한 원인은 표시용 물리의 곡선 복원 스프링과 굽힘 보정이었다. 기존 코드는 중간 점을 Bezier 안내 곡선으로 되돌리고, 양쪽 끝의 1~2개 점을 정해진 방향에 고정했다. 본체의 실제 매달림을 구현한 뒤에도 표시용 호스에 이 보정이 남아 있었다.

이번 수정은 `FluidExperimentDispenser.Motion.cs`의 호스 부분에 적용했다.

- 안내 곡선 복원력, 이웃 점으로의 굽힘 보정, 연결부 방향 고정을 제거했다.
- 양 끝의 위치만 연결하고, 자유로운 점은 중력·관성·감쇠와 최대 선분 길이 제약으로 움직인다. 느슨한 선분은 이웃을 밀어내지 않는다.
- 매달림 상태의 표시 길이는 실제 `DistanceJoint2D` 길이를 따른다. 항상 더하던 0.02u 여유 길이를 제거했다. 실제 장력이 걸린 줄은 보간된 본체 연결점까지 곧게 표시한다.
- Catmull–Rom 보간을 물리 점 안쪽에서만 모서리를 둥글게 하는 이차 곡선으로 바꿨다. 보간으로 생기는 연결부의 갈고리 모양을 방지한다.
- 폭 0.115u와 기존 프리팹 값, 본체의 실제 감김·진자 운동, 잡는 즉시 수직 복원하는 동작을 유지했다.

실제 Unity 6000.3.5f2 / D3D11의 분리된 프로젝트에서 실행했다. 아래 5회 모두 실제 종료 코드 0, 시간 초과 없음, 결과 PASS이며 총 3,974개 검증 항목을 통과했다. 실행 명령, 소스 해시, 검증 소스 스냅샷, 로그와 종료 기록은 각 실행 폴더에 보관했다.

|---|---|
| `20261022-cord-verified-dispenser` | 처짐·장력·연결부 접선·관성·30/60/120Hz, 입력·배출·재고·외부 충돌 억제·복귀·매달림 |
| `20261022-cord-verified-runtime` | 재사용 런타임, 독립 World와 카메라, 실제 줄에 의한 복귀 |

수평으로 6u 떨어진 연결점 사이에 줄 6.66u를 제공한 시험에서 중력으로 1.26627u 처졌고, 표시 길이는 6.66079u였다. 여유 길이를 회수하자 표시 길이 6u, 직선에서 벗어난 거리 0u가 됐다. 실제 네이티브 장력이 걸린 시험의 최대 직선 편차는 약 0.00000111u였다. 다시 느슨하게 하면 처짐이 한 프레임에 교체되지 않고 중력과 자유 점의 관성으로 점차 발생했다.

같은 연속 이동 경로를 30Hz와 120Hz로 적용했을 때 초 단위 측정점의 최대 위치 차이는 0.001351u, 이동 종료 후 2초가 지난 시점에는 0.000073u였다. 이전 진단 시험 `20261022-cord-v1-dispenser`는 서로 다른 프레임 시간에 0.8u 순간 이동을 주는 비교에서 실패했다. 이 시험은 기록으로 보존하고, 프레임별로 같은 연속 경로와 정지 속도를 갖도록 입력을 고쳤다. 길이·처짐·장력 검증 기준을 완화하지 않았다. `20261022-cord-v2-shape`는 순간 이동 후 긴 안정화 시간을 살펴본 별도 진단 기록이다.

본체의 감김 시간은 1.58초였고, 감김 뒤 초기 3초의 좌우 이동 폭은 1.31432u, 상하 이동 폭은 0.28805u였다. 호스 그림을 수정하면서 실제 본체를 당기는 기존 물리를 보존했음을 코드 비교와 재현 검사로 확인했다.

실제 카메라 프레임으로 만든 `slack-preview.gif`, `held-preview.gif`, `reel-preview.gif`, `hanging-preview.gif`를 함께 보관했다. 처진 줄, 팽팽한 줄, 이동 중·복귀 중·매달린 상태의 PNG도 직접 확인했다. 이는 숨김 실행의 물리 검사와 오프스크린 렌더 확인이며 사용자의 직접 플레이 체감 평가를 대신하지 않는다.

`audit.json`은 이번 작업 전 416개 파일의 해시와 비교해 런타임 변경이 호스 코드와 해당 README에 한정됐음을 확인한다. 본체 감김 코드, 프리팹·직렬화 에셋, 액체·얼음·가니쉬·파편, 사운드 코드·AudioPlanning·Packages는 작업 전 상태와 같다. 검증 도구에는 호스 형태 시험과 해당 입력 경로를 추가했다.
